## Copied or adapted files

None. Bluesky has no charts, so the chart components (`src/components/charts/*`)
are original Splito code on `react-native-svg`. Every control on the screen is an
existing Bluesky component already in the tree: `Button`, `Menu` (dropdown on web,
bottom sheet on native), `Dialog`, `Toggle` (checkbox), `Layout.Header`, `List`,
`Skeleton`, `Toast`, `UserAvatar`, `EmptyState`.
